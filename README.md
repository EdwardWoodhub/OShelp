# 简介

备选系统列表

| 系统名称 | 类别 / 基础 | 简介 |
| --- | --- | --- |
| **BlueBase** | Linux (Universal Blue) | 基于 Fedora Silverblue 的不可变（Immutable）容器化基础镜像，专为构建自定义云原生桌面定制。 |
| **Bluefin** | Linux (Universal Blue) | 基于 Fedora 与 BlueBase 打造的开箱即用不可变桌面系统，主打开发人员工作流与极高的系统稳定性。 |
| **CentOS Stream** | Linux (RHEL 上游) | 红帽企业 Linux（RHEL）的上游滚动预览版本，主要面向开发者和企业服务器环境测试。 |
| **Fedora** | Linux (独立发行版) | 红帽赞助的先锋发行版，以集成最新开源技术、现代化特性及高自由度著称。 |
| **macOS** | 专有系统 (Unix / Apple) | 苹果公司为其 Mac 系列电脑开发的专有操作系统，以精致 UI、生态联动与强大的专业生产力见长。 |
| **openSUSE Leap** | Linux (SUSE 下游) | 结合社区力量与 SUSE Linux Enterprise 核心的企业级稳定桌面/服务器发行版，配备强大的 YaST 管理工具。 |
| **Parrot OS** | Linux (基于 Debian) | 专为网络安全、渗透测试、数字取证及隐私保护设计的安全导向发行版。 |
| **Pop!_OS** | Linux (基于 Ubuntu) | 由 System76 开发，专为科学计算、开发和游戏优化，原生搭载 COSMIC 桌面环境并对混合显卡支持极佳。 |
| **Slackware** | Linux (独立发行版) | 现存历史最悠久的 Linux 发行版之一，遵循极简与 Unix 原生哲学，强调用户手动配置与极致控制权。 |
| **TUXEDO OS** | Linux (基于 Ubuntu) | 德国硬件厂商 TUXEDO 打造的桌面系统，搭载深度调优的 KDE Plasma，针对硬件驱动和游戏性能进行深度优化。 |
| **Ubuntu Budgie** | Linux (Ubuntu 官方风味) | 采用轻量级、现代且视觉优雅的 Budgie 桌面环境的 Ubuntu 官方衍生版本。 |
| **Windows** | 专有系统 (Microsoft) | 微软开发的全球市场份额最高的桌面操作系统，拥有最广泛的软硬件生态与游戏支持。 |
